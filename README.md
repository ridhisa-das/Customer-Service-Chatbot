# Customer Service Chatbot

## Project Description

This is a beginner-friendly customer service chatbot built using Python.

The chatbot responds to common customer queries using predefined responses.

##  Technologies Used

- Python
- Google Colab
- Basic NLP concepts
- Conditional statements

##  Features

- Answers common customer questions
- Provides simple predefined responses
- Easy to understand and modify
- Beginner-friendly Python project

##  How to Run

1. Open the `.ipynb` file in Google Colab.
2. Run the code cells from top to bottom.
3. Enter a customer query.
4. The chatbot provides an appropriate response.

##  Purpose

This project was created to learn the basics of chatbot development and Natural Language Processing.

##  Future Improvements

- Add more customer queries
- Use NLP techniques
- Add a graphical user interface
